## 🎯 我在做什么

- **Agent 工作流** — 任务拆解、工具调用、结果校验、失败自恢复
- **RAG** — 文档解析、分块、混合检索、带出处的答案
- **评测** — 建任务集 + 写评测脚本，并说清楚 *为什么* 会失败
- **数据 Agent** — Text-to-SQL、自动周报

> 我不信 demo。下面每个仓库都自带 **评测集、指标报告和失败分析**，点开就能复现。
